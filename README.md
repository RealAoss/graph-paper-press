# Graph Paper Press

Generate graph or dot paper in millimeters for A4 or US Letter, then print a sheet or save it to PDF.

## Open the app

Download `index.html` and open it in a modern browser. Everything runs locally. Work stays in the tab until you close it.

## Example

Select A4, Dots and 5 mm, then print or save to PDF. Each sheet has a 10 mm inset. Choose the matching paper size in the print dialog.

## Limitations

Work stays in the browser tab. Save the result before closing or refreshing the page.
